Retail Sales Analytics Dashboard

Overview: This project analyzes over 50,000 retail transactions using Microsoft Excel.

The objective was to transform raw sales data into an interactive dashboard capable of supporting business decision-making through KPI reporting, data visualization, and statistical analysis.

Tools & Skills Demonstrated:
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Dashboard Design
- KPI Reporting
- Data Visualization
- Statistical Analysis
- Business Analysis
