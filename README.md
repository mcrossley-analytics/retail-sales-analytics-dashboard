Retail Sales Analytics Dashboard
Overview
This project analyzes over 50,000 retail transactions using Microsoft Excel.

The objective was to transform raw transactional sales data into an interactive dashboard capable of supporting business decision-making through reporting, data visualization, and statistical analysis.
